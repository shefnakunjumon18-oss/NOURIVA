# NOURIVA — AI-Powered Recipe Generator and Personal Trainer

NOURIVA is a web application that helps users generate personalized recipes from available ingredients and explore fitness-related features.

## Features
- AI-powered recipe generation
- Personalized recipes based on available ingredients
- Fitness-oriented features for weight loss, weight gain, muscle building, and general fitness
- User and trainer modules
- Trainer booking and communication features

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Ollama

## Project Structure
- `app.py` — Flask application
- `templates/` — HTML templates
- `static/` — CSS, JavaScript, and other static assets

## How to Run
1. Clone or download this repository.
2. Install the required Python packages.
3. Run the Flask application using `python app.py`.
4. Open the local address displayed in the terminal.

*Note: Configure the required Ollama model and install the project dependencies before running the application.*
